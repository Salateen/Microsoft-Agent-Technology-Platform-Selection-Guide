# Microsoft Agent Technology Platform Selection Guide

An interactive decision framework to help you select the optimal Microsoft agent-building platform:  
**Copilot Chat Agent Builder**, **Copilot Studio**, or **Azure AI Foundry**.

---

## 🌟 Features

- Multi-step, interactive decision tree
- Minimalist, modern design for quick decisions
- Static, offline-friendly web app (no backend required)
- Platform feature cards and tailored recommendations
- Print-view support and accessibility features

---

## 🚀 Quick Start

### 1. **Clone or Download**

git clone https://github.com/salateen/agent-platform-selection-guide.git

Or download this repo as a ZIP and extract to your local folder.

### 2. **Open Locally**

Open `index.html` in your browser—no installation required.

### 3. **Host on GitHub Pages**

- Commit and push all files (`index.html`, `style.css`, `app.js`, etc.)
- Go to your repo **Settings** > **Pages**
- Set **Source** to your main branch and **/ (root)** folder
- Your tool will be live at:
https://.github.io//


---

## 🛠️ Customization

- **Logic/Steps**: Edit `app.js`
- **Styling & Branding:** Edit `style.css`
- **Content:** Update `index.html` as needed

## 📄 About

**Microsoft Agent Technology Platform Selection Guide** is designed for enterprise IT, architects, business analysts, and makers to identify which Microsoft agent-building solution best fits project requirements and technical preferences.  
Use this guide for internal evaluations, training, or as a decision-support resource.
